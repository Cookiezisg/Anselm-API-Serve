Anselm

Anselm is a personal AI application. The public API used by the app is hosted at api.anselm.website.

About

This domain is used to operate the Anselm application service. It is not an open proxy, public relay, or general-purpose AI gateway. API access is rate-limited and intended for Anselm clients.
